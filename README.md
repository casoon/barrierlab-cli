# barrierlab-cli

Accessibility audit of a web page from its source: one command, no browser. It fetches a page,
parses it and runs the [barrierlab](https://github.com/casoon/barrierlab) rule set over it.

```sh
barrierlab https://example.com
```

Documentation: [casoon.github.io/barrierlab-cli](https://casoon.github.io/barrierlab-cli/)
