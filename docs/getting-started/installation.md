---
title: Installation
description: Build the barrierlab binary from source with Cargo.
order: 1
---

`barrierlab` is a single Rust binary. It needs Rust 1.88 or newer and no browser.

```sh
cargo install --git https://github.com/casoon/barrierlab-cli
```

The binary is called `barrierlab`. Check the installation:

```sh
barrierlab --help
```
